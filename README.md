# 💱 Telegram-бот: Конвертер валют

Простой, быстрый и отзывчивый асинхронный Telegram-бот для конвертации валют в реальном времени. Написан на Python с использованием современных асинхронных библиотек.

## 🛠 Стек технологий
* **Python 3.10+**
* **aiogram 3.x** — асинхронный фреймворк для работы с Telegram Bot API
* **aiohttp** — асинхронные HTTP-запросы для получения актуальных курсов валют
* **asyncio** — управление асинхронным выполнением кода

## 🚀 Функционал
* Конвертация валют в один клик.
* Интуитивный интерфейс с использованием клавиатур.
* Быстрое переключение направлений обмена (прямой и обратный курс).
* Парсинг актуальных данных о курсах через внешнее API без задержек.

## 📁 Структура проекта
```
currency-converter/
├── bot.py           # точка входа: создание бота и запуск polling
├── config.py        # настройки: токен из .env, URL API ЦБ
├── cbu_api.py       # получение курсов с сайта ЦБ РУз (cbu.uz)
├── handlers.py      # клавиатура и обработчики сообщений
└── requirements.txt # зависимости
```

## 📦 Как запустить локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/dayvoens/currency-converter.git
   cd currency-converter
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` в корне проекта и укажите токен бота от [@BotFather](https://t.me/BotFather):
   ```
   BOT_TOKEN=ваш_токен
   ```

4. Запустите бота:
   ```bash
   python bot.py
   ```
